# 07. UI Rules & Component Behavior Standards

> **Objective:** Outperform legacy competitors (BookMyShow, Paytm Insider) with a cinema-heritage aesthetic, zero-friction mobile touch targets, and visual consistency across every single screen.

---

## 1. The Authentic Cinema Scallop Ticket Card (`get [my ▶] show`)

Every digital ticket pass generated by GetMyShow must follow the official geometry defined in `getmyshow-official-brand-kit`:

1. **Circular Sprocket Scallops (`∩∩∩`)**:
   * The top and bottom edges feature smooth circular scallops inspired by authentic 35mm cinema roll ticket pin-feed holes.
2. **Symmetrical Circular Waist Cutouts**:
   * Symmetrical semicircular notches on the left and right borders create the iconic perforated ticket stub silhouette.
3. **Vertical Dashed Perforation Line**:
   * A vertical dashed border (`border-dashed border-slate-700/60`) divides the main event info from the QR verification stub.
4. **QR Code Quiet Zone**:
   * The QR code must always sit on a clean, high-contrast white rounded square with at least 12px of white quiet-zone padding to guarantee instant scanning by gate camera sensors.
5. **Hyperlocal Sponsor Ad Banner**:
   * Positioned directly below the QR code stub: A clean rectangular card labeled `"Exclusive Event Partner Offer"` for local cafe/store coupons.

## 2. Button Hierarchy & Interactive States

| Button Type | Styling & Classes | Interaction & States |
| :--- | :--- | :--- |
| **Primary CTA** | `bg-brand-indigo hover:bg-brand-indigo-dark text-white font-semibold rounded-button px-6 py-3 shadow-[0_0_20px_var(--glow-indigo)]` | `active:scale-[0.98] transition-all disabled:opacity-50 disabled:cursor-not-allowed` |

| **Secondary / Ghost**| `bg-surface-elevated hover:bg-slate-800 text-text-primary border border-surface-border rounded-button px-5 py-2.5` | Used for modal cancellations, secondary links, and filters. |

* **Loading State Standard:** While a form or payment is in flight, the button text hides, an animated spinning circle (`animate-spin`) appears, and the element becomes unclickable (`pointer-events: none`).

## 3. Badges & Status Indicators

* **Pill Badges:** Always `rounded-full text-xs font-semibold px-3 py-1 flex items-center gap-1.5`.
  * **Verified / Active Event:** Emerald green (`bg-emerald-500/10 text-emerald-400 border border-emerald-500/20`).
  * **Pending T+2 Settlement:** Amber warning (`bg-amber-500/10 text-amber-400 border border-amber-500/20`).
  * **Live Stage / Happening Now:** Sunset Saffron (`bg-orange-500/10 text-orange-400 border border-orange-500/20 animate-pulse`).
  * **Gate Already Scanned (Alert):** Crimson danger (`bg-red-500/10 text-red-400 border border-red-500/20`).

## 4. Mobile-First Layout & Touch Rules

1. **360px Small Screen Baseline**:
   * Must look flawless on affordable smartphones (Redmi, Realme, Samsung Galaxy M series) common in Tier-2/3 Bihar.
   * Minimum touch target size for buttons and form fields: **$44\text{px} \times 44\text{px}$**.
2. **Sticky Mobile Checkout Bar**:
   * On mobile event detail pages (`/e/[slug]`), the event title, price, and "Book Passes" button remain pinned to the bottom of the viewport (`fixed bottom-0 left-0 right-0 z-50 p-4 bg-surface-card/95 backdrop-blur-md border-t border-surface-border`).
   * Eliminates the need for users to scroll past long descriptions to find the purchase button.
3. **Gate Scanner Viewport**:
   * Fullscreen dark layout (`#0A0D14`) with a centered neon scanner target reticle.
   * Full-screen flash transitions:
     * **Green Flash (`#10B981`)** for Valid Pass + Check-in Name & Seat count.
     * **Red Flash (`#EF4444`)** for Duplicate Pass ("ALREADY SCANNED AT 18:22").

---

## 5. Form Design & Minimal Friction

* **Single-Field Grouping:** Never overwhelm users with 15 form inputs. Group checkout into 2 crisp steps:
  * **Step 1:** Name + WhatsApp Number + Quantity.
  * **Step 2 (If applicable):** Custom coaching questions (Roll No, Class).
* **Keyboard Adaptation:**
  * Phone fields must specify `type="tel"` and `inputMode="numeric"` to trigger the numeric keypad on mobile.
  * Gate scanner PIN input must specify `type="password"` and `inputMode="numeric"`.
